# Weather Data

## Inputs

`noaa-data-us-units.csv`

Daily climate data from NOAA. Includes daily total precipitation in inches of water and snowfall in inches of snow.

`hourly-2017-03.pdf` and
`hourly-2017-03.xlsx`

Hourly precipitation in inches of water. The PDF came directly from NOAA and the XLSX file was exported from the PDF using Adobe Acrobat.
